### Ajibola Lawal

- **[homelab-sentinel](https://github.com/Arxchitect-tn/homelab-sentinel)** — an hourly health
  monitor for a self-hosted box: containers, resources, DNS, exposure, failed units. Graded exit
  codes so an expected warning doesn't blind the monitor itself.
- **[agent-mesh-dispatch](https://github.com/Arxchitect-tn/agent-mesh-dispatch)** — role routing
  for a multi-agent mesh, plus a three-stage write → review → final-review pipeline, and a
  restricted-key allow-list that lets a scheduler trigger work without holding a Docker socket.
- **[provider-shim](https://github.com/Arxchitect-tn/provider-shim)** — normalises OpenAI- and
  Anthropic-shaped clients onto one upstream endpoint, including auth-header rewriting.
